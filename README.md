# IBM Stock & Revenue Dashboard

A learning project from the IBM Data Science coursework, exploring historical stock prices and revenue for **Tesla** and **GameStop**.

## What the Notebook Covers

- Retrieve stock prices with `yfinance`.
- Extract revenue tables using Requests and Beautiful Soup.
- Prepare data with Pandas.
- Plot stock prices and revenue with Matplotlib.

## Project File

Open [`Revenue Data and Building a Dashboard.ipynb`](Revenue%20Data%20and%20Building%20a%20Dashboard.ipynb) to view the code and saved outputs.

## Tools

Python, Jupyter Notebook, yfinance, Pandas, Requests, Beautiful Soup, and Matplotlib.

## Notes

The notebook uses static Matplotlib charts and date limits defined in the coursework. Running the data-download cells requires an internet connection.

The original IBM / Skills Network coursework attribution remains in the notebook.
